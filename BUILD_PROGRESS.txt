Current Design Decisions
------------------------
- Project is standalone, not part of any forum flow.
- Local project path: C:\SOHAN1\cricket_guru
- One active tournament per guild.
- Organizer gate:
  - Administrator users pass.
  - Configured organizer role passes.
  - If no role configured, role named Organizer passes.
- Commands are hybrid where implemented, meaning slash and prefix versions work from the same command.
- Real secrets belong only in .env.
- .env is ignored by Git.
- .env.example must contain placeholders only.
- Round robin/group logic must generate rounds where a player has only one matchup at a time:
  - Round 1: A vs B, C vs D
  - Round 2: A vs C, B vs D
  - Round 3: A vs D, B vs C


Known Edge Cases To Handle
--------------------------
- Odd number of participants:
  - One random player receives a bye.
  - Bye match is marked as status bye.
  - Player auto-advances.

- Player registers twice:
  - Reject with:
    "You are already registered for this tournament."

- OVR below minimum:
  - Reject with:
    "Your OVR (X) is below the minimum required (Y) for this tournament."

- /post-result invalid match ID:
  - "Match #X does not exist in this tournament."

- /post-result winner mention is not in match:
  - "❌ @User is not a participant in Match #X. Valid players: A, B."

- /post-result winner mention is not registered:
  - "❌ @User is not registered in this tournament."

- /create-tournament when one is active:
  - "A tournament is already active. Cancel it first with /cancel-tournament."

- Groups not perfectly divisible:
  - Last group has fewer members and is still valid.

- /generate-matchups with fewer than 2 players:
  - "Not enough players registered (minimum 2 required)."

- rr_advance_count greater than registered player count:
  - Cap silently to registered player count.

- group_advance_count * groups is not a power of 2:
  - Add byes to pad knockout bracket to next power of 2.

- Round robin tied wins and tied OVR:
  - Tiebreaker is registration order.
  - Earliest registered player wins the tiebreaker.

- All players in a group withdraw/bye:
  - Group still completes.
  - Advance whoever remains.
